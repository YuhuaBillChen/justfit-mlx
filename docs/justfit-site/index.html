The capacity stack

Quantizing KV is only the first step. Usable context is set by every allocation that overlaps it.

The live budget includes weights, resident KV pages, floating-point attention operands, prefill workspace, output state, speculative state, and component lifetimes. JustFit treats their overlap as the systems problem.

One memory budget

Three cooperating mechanisms.

01KVEXEC

Compact in storage.
Bounded in execution.

Page-addressed Q4 KV, page-native decode and short verification, plus direct-inverse reconstruction of only the current layer's floating-point attention operands.

02PHASESWAP

Components follow
live owners.

The output head, vision tower, and singleton drafter attach when required, stay while leased, and detach only at scheduler-selected safe boundaries.

03STATETRANS

Change execution.
Keep the context.

A request can move MTP → batched AR → MTP without migrating its surviving target KV. Completed and cancelled rows return page IDs after evaluation.

Beginner Quick Start ↗

Run and reproduce

Start small. Pin everything.

The fork includes a component-preparation helper, explicit server launcher, streaming workload client, and path-sanitized result JSON.

  1. 01

    Pin the runnable kit

    git checkout justfit-repro-v4

    The immutable tag contains the current JustFit runtime, Quick Start, and version-scoped result manifests. Each reported cohort records its own measured runtime commit.

  2. 02

    Download pinned public artifacts

    hf download mlx-community/Qwen3.8-27B-mxfp4 --revision 97ab0819817ab1c61d7d39f9169fc71999915641 --local-dir ./justfit-models/qwen38-mxfp4
    hf download billchen42/JustFit-Qwen3.8-27B-components --revision 13e0462fa911a1bcbdccbaa759120500c0f90582 --local-dir ./justfit-components

    The component revision contains the exact production BF16 vision backing and byte-identical MTP weights.

  3. 03

    Extract language backings and run an 8K smoke profile

    export MODEL_PATH="$PWD/justfit-models/qwen38-mxfp4" MTP_PATH="$PWD/justfit-components/mtp" VISION_PATH="$PWD/justfit-components/vision-bf16.safetensors"
    python examples/justfit/prepare_components.py --model "$MODEL_PATH" --output ./justfit-extracted --language-only
    LM_HEAD_PATH="$PWD/justfit-extracted/language-head.safetensors" INPUT_EMBEDDING_PATH="$PWD/justfit-extracted/input-embedding.safetensors" LANES=1 KV_CAPACITY=32768 MAX_TOKENS=512 examples/justfit/run_server.sh

    The input embedding is extracted from the target locally, not downloaded again. Verify the component manifest before running.

  4. 04

    Archive the evidence

    Commit, checkpoint hashes, effective environment, stream completion, process peak, failures, and page-reuse postflight.
