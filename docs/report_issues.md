# Report Issues

Please open an issue on [GitHub](https://github.com/YuhuaBillChen/justfit-mlx/issues) with clear steps to reproduce the problem.

If the problem also reproduces on upstream mlx-vlm without the JustFit runtime,
report it at [Blaizzy/mlx-vlm](https://github.com/Blaizzy/mlx-vlm/issues) instead.
